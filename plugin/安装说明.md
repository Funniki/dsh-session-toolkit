# 会话功能增强（dsh-session-toolkit）安装说明

这是一个 **DSH 插件包**：插件列表里出现一个「会话功能增强」条目，里面包含五个组件，
每个组件保留自己的名称、图标和独立开关。

## 重要：不要只安装外层目录

DSH 按 **profile 根目录** 解析 bundle 里的组件包名，不会自动读取外层包自己的
`node_modules`。所以只安装 `dsh-session-toolkit` 会让五个组件显示“未运行”，并报：

```text
ERR_MODULE_NOT_FOUND: Cannot find package 'dsh-archived-session-delete'
```

必须同时把这五个组件加入 profile 依赖。安装脚本已经处理了这一步。

## 系统要求

- DeepSeek Harness 桌面端，版本 `>= 0.2.0`（当前 0.2.1 已验证）
- Windows PowerShell 7
- 无需 Node、无需构建；五个组件已随包内 `node_modules/` 带好；组件自身零第三方依赖，包内不再有 `@deepseek-ai/*` 依赖树

## 推荐安装

1. 把压缩包解压到固定目录，例如：
   `C:\Users\<你>\dsh-plugins\dsh-session-toolkit-0.1.0`
   > DSH 以链接方式安装本地目录；安装后不要移动或删除这个目录。
2. 在解压目录运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. 重启 DSH，或在插件页先把「会话功能增强」关闭再打开。
4. 打开「插件 → 会话功能增强」，确认：

   ```text
   共 5 个 · 5 运行中
   ```

## 手动安装

如果不使用脚本，需要安装主包和五个组件：

```powershell
$dsh = "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"
$root = "C:\Users\<你>\dsh-plugins\dsh-session-toolkit-0.1.0"

& $dsh plugin --profile desktop add $root
foreach ($name in @(
  "dsh-archived-session-delete",
  "dsh-session-move",
  "dsh-unsent-content-guard",
  "dsh-session-history-search",
  "dsh-auto-paste"
)) {
  & $dsh plugin --profile desktop add (Join-Path $root "node_modules\$name")
}
```

安装后检查 profile，确认顶层没有重复的核心包：

```powershell
$profileDir = Join-Path $HOME ".dsh\profiles\desktop"
Test-Path (Join-Path $profileDir "node_modules\@deepseek-ai\dsh-tools")  # 应为 False
```

## 使用入口

- 已归档会话行悬停 → 红色删除按钮；会话菜单 →「删除已归档会话」
- 会话「...」菜单 →「移动到工作区…」（需要至少两个工作区）
- 输入框下方 →「未发送备份」胶囊
- 输入框「搜索历史」或 `Ctrl+Shift+K`
- 粘贴超过阈值的长文本 → 自动保存到工作区 `pastes/`

## 数据位置

- 删除/移动会话：`%USERPROFILE%\.dsh\session-workspace-move\`
- 未发送内容备份：`%USERPROFILE%\.dsh\unsent-content\`
- 卸载插件不会自动删除这些数据。

## 已知边界

- 打开过的会话不能即时迁移：会排队，重启 DSH 后自动完成。
- 删除归档会话不可恢复。
- 只支持当前 DSH 会话格式 v4。
