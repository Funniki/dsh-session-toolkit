# 会话功能增强（dsh-session-toolkit）安装说明

这是一个 **DSH 插件包**：插件列表里出现一个「会话功能增强」条目，里面包含五个组件，
每个组件保留自己的名称、图标和独立开关。

当前版本 `0.1.0`，npm 上为 `@funniki/dsh-session-toolkit` 及五个
`@funniki/dsh-session-toolkit-*` 组件包。

## 重要：不要只安装外层

DSH 按 **profile 根目录** 解析 bundle 里的组件包名，不会读取外层包自己的
`node_modules`。所以只安装 `@funniki/dsh-session-toolkit` 会让五个组件显示“未运行”，并报：

```text
ERR_MODULE_NOT_FOUND: Cannot find package '@funniki/dsh-session-toolkit-archived-session-delete'
  imported from C:\Users\<你>\.dsh\profiles\desktop\
```

必须同时把这五个组件加入 profile 依赖。安装脚本已经处理了这一步。

> ⚠️ 不要用仓库目录直接安装：本地安装会记成 `link:`，插件页「卸载」会连带清空链接目标里的文件。
> 仓库只用于开发和构建；安装请走 npm，或把 zip 解压到独立目录再装。

## 系统要求

- DeepSeek Harness 桌面端，版本 `>= 0.2.0`（0.2.1-rc.5 已验证）
- Windows PowerShell 5.1 或更高（`install.ps1`）
- 无需 Node、无需构建；五个组件已随包内 `node_modules/@funniki/` 带好，
  组件自身零第三方依赖，包内不再有 `@deepseek-ai/*` 依赖树

## 推荐安装（zip 渠道）

1. 把压缩包解压到固定目录，例如：
   `C:\Users\<你>\dsh-plugins\dsh-session-toolkit-0.1.0`
   > DSH 以链接方式安装本地目录；安装后不要移动或删除这个目录。
2. 在解压目录运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. 重启 DSH，或在插件页先把「会话功能增强」关闭再打开。
4. 打开「插件 → 会话功能增强」，确认：

   ```text
   共 5 个 · 5 运行中
   ```

## 安装（npm 渠道）

不改用 zip 时，这个脚本也能直接装：包里没有本地组件副本，它会自动从 registry 装
`@funniki/*` 的六个包。手动版本是逐条执行：

```powershell
$dsh = "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd"

& $dsh plugin --profile desktop add @funniki/dsh-session-toolkit
foreach ($name in @(
  "@funniki/dsh-session-toolkit-archived-session-delete",
  "@funniki/dsh-session-toolkit-session-move",
  "@funniki/dsh-session-toolkit-unsent-content-guard",
  "@funniki/dsh-session-toolkit-session-history-search",
  "@funniki/dsh-session-toolkit-auto-paste"
)) {
  & $dsh plugin --profile desktop add $name
}
```

## 装完检查

安装脚本在结束前会自动核对：bundle 已注册、6 个依赖已记录、profile 里没有重复的核心包。
想再手动确认一遍：

```powershell
$profileDir = Join-Path $HOME ".dsh\profiles\desktop"
Test-Path (Join-Path $profileDir "node_modules\@deepseek-ai\dsh-tools")  # 应为 False
```

## 使用入口

- 已归档会话行悬停 → 红色删除按钮；会话菜单 →「删除已归档会话」
- 会话「...」菜单 →「移动到工作区…」（需要至少两个工作区）
- 输入框下方 →「未发送备份」胶囊
- 输入框「搜索历史」或 `Ctrl+Shift+K`
- 粘贴超过阈值的长文本 → 自动保存到工作区 `pastes/`，输入框留一张带预览的卡片

## 数据位置

- 删除/移动会话：`%USERPROFILE%\.dsh\session-workspace-move\`
- 未发送内容备份：`%USERPROFILE%\.dsh\unsent-content\`
- 长文粘贴阈值：`%USERPROFILE%\.dsh\auto-paste\user-config.json`
- 卸载插件不会自动删除这些数据。
